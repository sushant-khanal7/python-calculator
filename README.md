# Python Simple Calculator 🧮

This is the very first Python program I built! 

This project helped me learn how to think like a developer by turning basic math logic into a functional command-line tool. 

## What can it do?

The script takes two numbers and an operator from the user to handle basic math:

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)

**Bonus feature:** I added a safety check so the program won't crash if someone accidentally tries to divide a number by zero it will return error.

## How to run

1. Check that you have Python set up in your laptop/computer.
2. Download or clone these project files.
3. Open up your terminal or VS Code inside the project folder.
4. Run this quick command:

```
python calculator.py
```

## Example

```
Enter your 1st Number: 10
Enter your 2nd Number: 5
Enter the operator: *

Product is: 50.0
```
